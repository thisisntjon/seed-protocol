# Bonkers proof-of-concept program

The registry at `POC-REGISTRY.json` is the source of truth. A POC is complete only when its
named functionality works and its evidence can turn red on the defect it claims to detect.
Activity, code volume, and infrastructure do not advance the bar by themselves.

The first ten POCs are ordered by dependency, not spectacle:

1. cold-start comprehension;
2. deceptive-green evaluator;
3. context-loss recovery;
4. verified-loop accounting;
5. retraction propagation;
6. second-project transplant;
7. safe upgrade and local-fork protection;
8. human intervention capture;
9. bare-versus-SEED calibration;
10. public thermometer.

Run `python scripts/poc_status.py` for the live view and `python scripts/poc_check.py` for
machine-scored calibration. Synthetic fixtures validate instruments only; they do not support a
claim that SEED helps or that autonomous agents can complete real projects.
