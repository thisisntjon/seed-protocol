# Measurement discipline (portable)

Strip of any domain. Rebuild power numbers and calibration for **this** runtime.

1. **Local eval is a filter, not a predictor** until a live calibration exists.
2. **Power the instrument** for the effect you care about. Underpowered "null" is
   UNKNOWN, not refuted.
3. **Cite the powered study, not the smoke.**
4. **Reachable ≠ selected ≠ executed.** Ask which object and demand the hash.
5. **Age is not maturity.** Frozen arms look converged. Record froze_at.
6. **Pair-mean, not winner's curse.**
7. **No point bar on n=2–3.** Publish an interval.
8. **A path you cannot read is not empty.** Name the machine.
9. **Self-similarity is not an opponent.**
10. **The ship path must carry the logic.** Knobs the loader never sees do not exist.
11. **Vacuous counters are not evidence.** Require a candidate-specific nonzero counter.
12. **Skipped checks are not a pass.** Print how many actually ran.
13. **If there is no seed API, do not pretend paired eval.**
14. **A flat pooled score can hide the band that matters.**
15. **Latency claims only from the mode that can support them.**
16. **Config overrides through one API, then assert they landed.**
17. **Dead-end rows carry a scope guard.**
18. **Arithmetic can close a door without cell-count theater.**
19. **Agreement-with-champion cannot prove improvement on the champion.**
20. **"It imported" is not "it ran."**
21. **Every result file carries code hash, data hash, config, experiment id.**

Suspect leakage first on any surprise positive. No arm is spoken about before its
matched control exists. A number in a report is backed by an artifact in the same change.
