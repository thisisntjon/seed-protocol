# Archive policy — never delete, always preserve

| Allowed | Forbidden |
|---|---|
| Add `Status: ARCHIVE` / supersession banner | Silent `git rm` of research, receipts, inventories |
| Point CURRENT surfaces at successors | Rewrite history to erase a wrong-era claim with no retraction |
| `git mv` only with a register row | Dropping a pointer so the next seat believes it never existed |

**Why:** multi-agent fleets re-derive from old citations; missing files look like
"n=0 / never done." Retractions require the false claim to still be findable.

Leave the file; mark ARCHIVE; list the successor. SEED overwrites *current-truth*
files (START-HERE, PLAN) in place — that is a different rule. Research and receipts
archive; current-truth edits.
