# AUTONOMY — action tiers

If an action class is not in the STOP table, it is LOG-AND-CONTINUE. Incidents add a
machine check or a checklist line — never a new prose rule. This page LOOSENS when error
budgets stay healthy.

## Staging ladder

Zero-key (reversible scratch) → one-key (author freezes bar) → two-key (independent
confirm) → Principal-key (irreversible).
