## Binding rules

1. **INCLUDE cap.** The public object is no larger than **CORE + factory bins +
   case-study research + hygiene/front-door files**. Those four buckets are the
   maximum set, not a prompt to dump the current START-HERE file map.
2. **MVS keep (patterns, not a file dump).** Claim-by-push, verdict tokens, frozen
   gates, irreversibles. Already encoded in `AGENTS.md`, `GATES.md`, and CORE
   templates. Do not import Pokemon `verdict_lint.py` or a campaign board to
   "have" them.
3. **MVS skip (conversation + this repo, 2026-09-01).** Squad, artifact broker,
   `queue_worker`, daemon heartbeats. **Default-fleet mailbox is also out** of
   the public object (see EXCLUDE). Playbook `BOOTSTRAP.md` MVS still *keeps*
   mailbox + status + digest for a live two-agent shop; that is an operating
   subset, not a display subset. This repo's override is DECISIONS 2026-08-08
   (solo default; 30-day fleet produced zero confirmed improvements),
   `HARDENING.md` ("no fleet mailbox"), and the 2026-08-31 handoff ("Do not
   build a fleet mailbox").
4. **C-004 stays HYPOTHESIS.** A public tree that reads as a proven treatment
   effect is out of genre (DECISIONS 2026-08-31).
5. **This brief writes no capability READMEs and no harvest idea rows.**
