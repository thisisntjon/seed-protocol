# Phase P3 — Bare-versus-SEED causal ablation

State: PLAN GATE  
Date: 2026-08-08  
Research: `workflow/research/phase-P3-ablation-design.md`

## Produces

A blinded, reproducible, fixed-sample comparison of bare project instructions versus the exact
P2c-proven SEED protocol on twelve matched tasks, with protected behavioral scoring and complete
human/time/token/cost accounting.

## Verifies

Whether SEED reduces invalid completion claims without lowering correct completion or increasing
live human intervention beyond the preregistered bounds. A null or harmful result is a valid
terminal.

## Phase boundary

Approval of this plan authorizes Steps 1–4: preregistration repair, local instrumentation, corpus
construction, and excluded calibration design. It does **not** authorize the 24 solver runs. The
fixed run opens only after its exact model/configuration and conservative cost are recorded and any
required spend gate is answered.

### 5. Excluded calibration and price gate

Actions:

- run one clean and one defective calibration outside the registered corpus;
- fix only instrumentation/isolation defects; never tune treatment or scoring to favor an arm;
- forecast 24-run duration/tokens/attempts/cost from the larger run plus 25% contingency;
- open a human gate only if the forecast exceeds the verified pre-authorized runway.

Done when: two calibration receipts are terminal; cost forecast and exact solver identity are frozen;
the run is either within runway or has an answered gate.

### 6. Execute the fixed twelve pairs

Actions:

- run all 24 isolated terminals without partial outcome reading;
- allow infrastructure retries only under predeclared retry classes;
- quarantine invalid pairs without replacement unless the preregistration already names replacement
  behavior;
- blind-score all artifacts and verify run completeness.

Done when: all registered terminals and traces exist or the experiment reaches a predeclared invalid
terminal; no result-dependent change occurred.

### 7. Analyze, reproduce, and close

Actions:

- run the frozen analysis from blinded labels, then unblind once;
- independently recompute the paired outcomes and exact test;
- record PASS, KILL, NULL, or INVALID-INSTRUMENT without narrative rescue;
- update C-004 and POC-09 only to the strength the result supports.

Done when: analysis and independent reproduction agree; receipt binds all hashes, costs, human time,
and limitations; `workflow/PLAN.md` records the terminal and next pivot.

- No hidden exact-token answer key or preferred evidence-path allowlist.
- No partial outcome reading, optional stopping, treatment stacking, or three-arm expansion.
- No claim that portability or cold onboarding already proves causal benefit.

## Open assumptions

2. Human intervention can be captured prospectively with acceptably low missingness and observer
   effect.
3. Twelve pairs can produce a decision-grade directional result under the exact small-sample rule;
   a null remains likely and acceptable.
4. A fixed solver/configuration can be obtained and metered reproducibly across 24 fresh contexts.
